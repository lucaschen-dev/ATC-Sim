# Build 23 — Radar rebuild and special coordination

**Build:** 23  
**Version:** 0.1  
**Record:** Retrospective release notes

## Changes

- Rebuilt APP/ACC presentation with gray procedure lines, solid upward waypoint triangles, nearby airports and clearer terrain.
- Removed gray triangular elevation clutter and retained spaced source-grid high points.
- Changed precipitation to continuous intensity boundaries with important labels drawn above it.
- Added contextual pilot requests, independently triggered emergencies, four-digit octal squawks, priority, rescue and diversion coordination.

## Scope and limitations

Displayed terrain smoothing does not increase the resolution of the original elevation grid. Emergency probabilities are gameplay settings.
