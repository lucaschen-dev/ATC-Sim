# ATC Sim v1.1.4 · Build 53

- **Report on GitHub** prepares a ZIP and opens the project’s issue form with the version, position and issue description filled in.
- Drag the ZIP onto the form's attachment field to upload it. The game can also reveal it in Finder or export a standalone local copy.
- The archive contains the description and the last ten minutes of eligible game diagnostics. Save failures use a generic message so that local paths are omitted.
- Includes the radio and ground changes from [build 52](https://github.com/lucaschen-dev/ATC-Sim/releases/tag/v1.1.3).

This release publishes documentation only.
