# Build 17 — Six more airports and airport workflow

**Build:** 17  
**Version:** 0.1  
**Record:** Retrospective release notes

## Changes

- Added Macau, Nanchang, Wuhan, Chongqing, Hangzhou and Harbin; airport selection used a China map.
- Added a staged airport-package workflow with source geometry, constraints, airspace and terrain.
- Corrected app-icon metadata and preserved existing progress.

## Scope and limitations

The former map selector and airport-authoring workflow are historical features. The current game uses airport cards and the editor was removed in build 45.
