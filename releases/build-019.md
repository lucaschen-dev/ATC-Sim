# Build 19 — Macau linework and four capital airports

**Build:** 19  
**Version:** 0.1  
**Record:** Retrospective release notes

## Changes

- Separated Macau's five main taxi guidance paths from 1,743 reference curves and removed duplicated guidance.
- Added Changsha, Zhengzhou, Jinan and Fuzhou with individual ground, navigation, terrain and traffic data.
- Repaired Jinan A1's source-obscured connection while retaining a separate runway-clearance requirement.
- Corrected switching from VOR to a supported ILS context.
