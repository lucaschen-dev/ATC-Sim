# Build 33 — Conflict forecasts, tug recovery and constraint calls

**Build:** 33  
**Version:** 0.1  
**Record:** Retrospective release notes

## Changes

- Forecast ground conflicts from cleared routes and show one focused conflict point with two route previews.
- Use red waves at the source conflict point and normal calling-aircraft attention with steady transparent tags.
- Add tug recovery: 60 simulated seconds to arrive, a 180-second dispatch cooldown and a five-point satisfaction cost.
- Announce arrivals before touchdown and simulate runway rollout and source-connected exits; let controllers set ARR/DEP/MIX/CLOSED roles.
- Improve carrier/terminal stand preferences and local numeric edits with grid snapping.
- Place reviewed altitude/IAS limits above their fixes and make crews call about approaching unmet limits.
- Correct emergency/local-destination ILS eligibility and stale airport aliases.
