# Screenshot provenance

These images are actual captures of the installed game window retained from development verification. They are not AI-generated images, concept art, a satellite image or reconstructed promotional mockups. The original PNG bytes are retained, including the game's Chinese interface. English explanatory captions are provided in the README.

| Repository image | Capture | What it demonstrates |
|---|---|---|
| `assets/ground-pudong-build31.png` | ZSPD / GND, build 31, 2026-11-03 | Ground map with real application panels, aircraft/stand selection and taxiway guidance. |
| `assets/approach-hong-kong-build25.png` | VHHH / APP, build 25, 2026-10-31 | Installed approach radar with tags, terrain, nearby airports, ILS controls and coordination. |

Both frames contain only the game window, without the user's desktop or unrelated applications. Neither is presented as a build-48 screenshot. Later releases changed ground linework, aircraft symbols/scaling, interface details and some request wording. A screenshot illustrates appearance at capture time; it does not prove every depicted procedure or clearance is valid.
